# miniC evaluation

Package [miniC](https://github.com/PlantG3/miniC) was developed to distinguish if a sequence is from core or mini.

1. Package miniC can be used to determine if a genome contain mini(s): [1c_miniPred.sh](1c_miniPred.sh). Whole genome sequencing data could be the input. Typically Illumina trimmed clean reads are used as inputs.

2. Package miniC can also be used to scan a sequence (e.g., chromosome) to undertand the distribution of mini-like sequences: [2c_scan.sh](2c_scan.sh)
